# 工程总览卡

个人 AI 仪表盘的独立工程总览卡（项目雷达替代方案）预览。

这次发布只包含工程总览卡，不包含仪表盘的其他输入、知识、日记或今日安排卡片。

## 这张卡展示什么

- 产品项目与卡片项目的目录层级和隔离关系
- 当前选中项目的工作树、分支、HEAD、未提交文件、合并状态、PR / Review / CI 登记
- 一个项目的原始需求、职责边界、路线图和历史快照
- “首轮构建”和“后续迭代”两个工作模式
- 需要处理的跨卡冲突，以及一张卡 / 一条分支 / 一个工作树的隔离规则

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端提示的本地地址。生产构建和测试：

```bash
npm run build
npm test -- --run
```

## 当前数据边界

这是工程总览卡的静态现场快照。它不会假装已经连接 GitHub、Linear 或 CI；页面中明确标出“未连接”的外部状态。后续如果接入真实仓库，应由本地 Git、GitHub、CI 和项目文档提供事实，页面只负责汇总展示。
